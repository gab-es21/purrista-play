# Purrista

A cozy 3D arcade-idle cat café game, made for YouTube Playables.

**▶ Play it here: https://gab-es21.github.io/purrista-play/**

Take over Grandma Rosa's run-down café in the little town of Willow Creek and bring it back to life: clean it up, brew and serve coffee, build tables and machines, hire workers, open the park, the river and the city, and collect cats and other animals, in regular, gold and rare Stardust versions. Find every key in town to buy a train ticket to Paris.

Plays on phones and desktop: drag anywhere to walk, tap to act.

This repository holds only the built game, for playing in the browser. The source code is private.
